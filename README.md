# Grampa Survivors

A browser-based survivors-style game built with Flutter - a work in progress with terrible humour.

## Play online

https://gordongrahamtesting.github.io/survivors/

## Run locally

```bash
flutter run -d chrome
```

To build the web release:

```bash
flutter build web --release
```

Pushes to `main` automatically build and deploy the web game to GitHub Pages.
